# S3 人工验证清单

状态：等待人工验证。请使用 [S3 Windows x64 ZIP](../dist/RatsSearch-Windows-x64-s3.zip)，保留现有稳定/S0/S1/S2 包与用户数据。

## 启动与恢复

- 解压到新目录。建议先用全新、ASCII 路径的数据目录，例如 `RatsSearch.exe --data-dir E:\RatsS3Test\data --no-remember-data-dir`；此选项不改变下次默认启动目录。下载目标可以使用中文/日文/emoji 路径。
- 数据库使用第三方 Manticore。本次整包烟测发现中文数据库数据目录不能可靠启动，暂使用 ASCII 数据目录；这与下载目标 UTF-8 路径是不同路径，不将数据库问题标为已修复。
- 用备份的 S2 会话检查迁移：文件选择确认、原始索引、任务限速、用户暂停不丢失；高级配置补默认值，保存为版本 2；未知版本或损坏 JSON 不能被静默覆盖。

## 高级下载

- 任务设置切换稀有优先、顺序、首尾优先，运行中切换并重启。文件哈希/内容必须不变；跳过文件不落盘。首尾策略只影响所选文件，不保证媒体一定能预览。
- 分片图每约 3 秒更新：绿色已校验、蓝色活动、灰色待下载、深色跳过；每格可能汇总多个分片。大种子打开设置仍应保持响应。
- 自动窗口设置上下界；手动设置 1、2、32、128，并在运行中调低。旧请求允许收敛，但新请求不得绕过全局在途预算、限速与磁盘背压。检查 TCP 和 uTP+MSE。
- 缓存从 0 开启到 4/64 MiB，再降低或关闭；多任务共享预算。删除文件后重新校验、切换选择、错误后重试均不应继续使用失效缓存。进程总内存不等于读缓存数据预算。

## 时间计划

- 全局设置增加每周时段：指定星期、开始/结束、本地 IANA 时区、上下行上限或暂停内容传输。结束 00:00 表示午夜，允许跨午夜；重叠、空星期、无效时区应被拒绝。
- 在当前时间前后设置切换点，观察约 1 秒轮询生效。计划结束后回到普通全局/任务上限；手动暂停的任务不能被计划恢复。
- 任务 0/继承不能突破计划或全局上限；后台 BT 内容仍受共享预算。
- 检查夏令时地区：不存在的本地分钟不会执行，重复的本地分钟使用同一规则；做种活动时长不按本地墙钟差分计算。

## 做种条件

- 分别设置全局分享率/活动时长，任务继承或覆盖；0 表示该条件关闭。任一/全部只组合已启用条件；全部关闭不能立即停止。
- 所选完成的部分任务也适用停止条件，但不触发完整种子完成或完成后移除。
- 暂停和排队期间不累计活动做种时长。达到条件应释放做种槽，保留文件并显示原因；不能改成用户暂停意图。
- “达到目标后重新做种”重置本轮活动时长与上传计数基线。调整条件后重新判断；重启保留累计时长、基线和目标状态。

## 回归重点

复查 S1 双层限速/并行数与 S2 文件选择、中文路径、边界辅助文件、重新校验。人工反馈请附任务策略、计划时区、文件选择、日志及复现步骤。通过前不将本包替换为正式稳定发行。
