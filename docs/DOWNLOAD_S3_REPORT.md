# S3 实施与交付报告

状态：实施、最终构建及自动验证完成；等待人工验证。用户于 2026-11-19 明确要求继续 S3，实施范围与函数映射见 [执行记录](DOWNLOAD_S3_PLAN.md)。未提交 Git commit 或对外发布。

## 功能与接口

- **下载策略**：稀有优先、顺序、所选文件首尾分块优先。只调整 picker，不改元数据、info hash 或协议 block 大小；保留文件选择和磁盘/限速门禁，运行中已发请求自然收敛。
- **有界请求窗口**：[RequestWindowPolicy](../src/librats/src/librats/bittorrent/download_strategy.h) 默认自动 2–32，无测量时用 32；使用逐请求响应延迟、平滑接收速率和磁盘队列推导目标，手动 1–128。仍受 S1 全局/任务在途与带宽预算约束，配置值不等于保证的实际在途数量。
- **共享读缓存**：[DiskCacheBudget](../src/librats/src/librats/bittorrent/disk_cache_budget.h) 默认关闭，最多 256 MiB 读负载数据、4096 个 LRU 条目；全 Client 共享。写入、重检、映射切换与停止后失效，代次隔离晚完成读取。索引、临时读取副本和既有写队列另计，不把缓存容量宣传为进程内存上限。采用保守的全缓存失效，未实现写回缓存。
- **分片图**：按需 reactor 快照，最多 2048 个聚合半开区间，包含 verified/wanted/active/high 计数；普通进度推送不携带整幅图。[界面](../src/ui/downloadadvancedwidgets.cpp) 在任务设置可见时约每 3 秒更新，默认 256 格。
- **调速计划**：[BandwidthSchedule](../src/services/download_advanced_policy.cpp) 使用 IANA 时区、本地星期与分钟，支持跨午夜，最多 64 个不重叠时段。夏令时缺失分钟不执行，重复分钟使用相同规则；额外上限与全局/任务上限取交集，计划暂停不改变用户暂停意图，约 1 秒轮询生效。
- **做种目标**：全局默认与任务继承/覆盖，分享率千分比、活动秒数，支持任一/全部已启用条件。全为 0 不停止；所选完成才累计活动做种时长，暂停/排队不计时。达到目标释放槽位，保留文件与用户意图。重新做种重置本轮账本；零字节目标不能满足分享率条件。
- **持久化**：策略与会话版本 2，读取版本 1 补安全默认，保留 S2 已确认选择。独立保存 `seededMilliseconds`、`seedingUploadedBytes`、停止状态；引擎传输计数重启归零不丢分享率进度。达到目标的恢复任务仍能先校验元数据/文件。配置损坏或未知版本拒绝覆盖，并阻止应用按默认下载限制启动。
- **界面/API**：全局设置增加缓存、周计划、默认做种条件；任务设置增加策略、窗口、做种条件及分片图。新增 pieces.get、schedule.get/set、seeding.set，保留既有 policy/file API；详细契约见 [API](API.md#s3-advanced-download-policies)。中文主要文案、[手册](MANUAL.md)、[服务端说明](SERVER.md) 已同步。

没有删除公开 API。新增 [启动参数](../src/main.cpp) `--no-remember-data-dir` 用于隔离验证/便携运行，不改变用户下次默认目录。

## 验证

[S3 专项测试](../tests/test_download_s3.cpp) 覆盖：严格策略验证与版本迁移、损坏/未知配置保留、跨午夜/重叠/无效时区、纽约春季跳时与秋季重复分钟、整数分享率边界、自动/手动窗口边界、共享 LRU/代次失效、外部文件修改后重检失效、计划准入切换、做种计时/重启账本、停止目标任务恢复元数据、真实 TCP 与 uTP+MSE 顺序下载/首尾映射/分片汇总、最终内容逐字节比较。

最终完整 CTest **26/26 通过，127.07 秒**，包括原 118 项底层 GTest及收尾恢复/配置保护测试。S1 的两个 60 秒真实限速场景继续运行，S2 选择性/边界存储回归保留。PowerShell 构建脚本语法、翻译 XML 和修改文件空白检查通过。

新增 [整包烟测程序](../tests/download_package_smoke.cpp)，默认构建时从实际 ZIP 解压到中文目录，以仅含包目录/Windows 系统目录的 PATH 运行应用。使用本地 Tracker/Seeder，512 KiB 中文文件和中文下载目标，确认文件后真实下载并逐字节比较，再强制重启检查任务策略与全局缓存设置保留。测试拥有独立进程树、全新数据目录，不更改用户记住的数据目录。最终实际 ZIP 烟测通过，应用版本为 2.0.0.1516。

## 性能与资源

沿用 [32 MiB localhost TCP 夹具](../benchmarks/download_benchmark.cpp)，256 KiB pieces、Release、无 MSE/uTP/DHT，每版本 3 次并比较完整内容。S2 使用此前保存的独立基准程序；S3 使用同一机器/工具链的最终底层库。

| 场景 | 吞吐中位数 MiB/s | 三次合计 CPU 秒 | 观察到的进程峰值 MiB |
|---|---:|---:|---:|
| S2 | 5.977 | 4.281 | 102.770 |
| S3 默认，自动窗口、缓存关闭 | 5.797 | 4.172 | 78.840 |
| S3 首尾策略、窗口 32、每 Client 4 MiB 缓存 | 5.989 | 4.438 | 82.570 |

默认吞吐相对 S2 **-3.01%**，满足不超过 5% 回退的门槛；启用高级参数样本约 **+0.21%**。逻辑内容写入均 33,554,433 字节，写放大约 1.00000003。缓存场景比默认进程峰值约多 3.73 MiB，符合显式读数据预算规模。

原始数据：[S2](validation/download-s3-s2-benchmark.json)、[S3 默认](validation/download-s3-benchmark.json)、[S3 高级](validation/download-s3-advanced-benchmark.json)。每组仅 3 次，包含本地下载与做种两端、测试缓冲区；不能据此推断普遍提速或内存下降，逻辑写放大也不是 SSD 物理写放大。缓存保留数据上限另由预算/淘汰测试验证。

## 已知限制与人工门槛

- 整包验证发现第三方 Manticore 在中文数据库数据目录下启动超时，本阶段未修复；实际下载验证采用 ASCII 数据目录，包路径/下载目录/下载文件名使用中文。不能将下载 UTF-8 路径验证解释为数据库 Unicode 数据目录已支持。
- UI 交互、真实公网多任务与各种媒体预览需人工验证；首尾/顺序倾向不保证可播放。大种子分片图是聚合概览，查询需扫描 picker，不建议高频轮询。
- 计划控制 BT 内容，不承诺整个进程网络静默；已发请求可短暂收敛。读缓存默认关闭，开启不保证每种负载提速。

请按 [S3 人工清单](DOWNLOAD_S3_VALIDATION.md) 验证。通过前保持阶段验证包，不替换正式稳定发行。
