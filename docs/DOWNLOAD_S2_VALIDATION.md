# S2 人工验证清单

状态：等待人工验证。S1 已由用户确认通过；本阶段不进入 S3。

## 验证包

使用 [Windows x64 S2 ZIP](../dist/RatsSearch-Windows-x64-s2.zip)，解压到新的中文目录，启动程序。建议使用独立数据目录：`RatsSearch.exe --data-dir .\data-s2`，先备份原会话与下载目录。

## 操作检查

- 新建磁力下载：先获取元数据，文件选择确认前不能收到内容数据；打开任务设置确认文件。关闭选择窗口应保持等待确认。
- 新建多文件种子：目录支持三态勾选；按文件名或扩展名筛选后，可批量选择/跳过匹配文件。确认普通/高优先级，确认实际原始文件索引正确，不受目录排序影响。
- 只选择中间文件，且其起止都不在分块边界：比较下载结果内容/校验值；未选文件不能在新的目标目录中出现。`.parts/<hash>/` 的辅助数据用于完整分块校验，不要手动删除。
- 运行中切换选择，连续点击确认、同时暂停/恢复、移除任务：不能崩溃，版本冲突或忙状态应明确提示；失败时窗口保留。
- 所选文件完成：显示部分做种，进度以所选文件字节加权；不能触发整种完成或“完成后移除”。再选择更多文件应恢复下载。
- 全部跳过：不调度内容下载。仅选空文件：创建空文件并完成所选内容。
- 中文、日文、emoji 文件名：正常保存。Windows 保留名、非法字符应报告错误，不得创建乱码目录或写到目标目录以外。
- 重启应用：保留优先级与选择版本，重新校验文件和辅助数据。旧会话缺少确认信息时保持暂停，手动恢复获取元数据后重新确认。
- 删除已下载文件后执行“重新校验 / 重试文件”：已校验量下降并能重新下载。权限/磁盘错误修复后重试可恢复；普通恢复不清除磁盘错误。
- 部分做种任务能向其他端上传自己已校验的完整分块。高优先级资源不可用时，普通优先级可用资源仍应继续。
- 复查 S1 全局/任务限速、下载并行数、做种并行数与队列优先级没有退化。

## 注意

跳过已存在的文件不会删除其内容；选择性下载的“不创建跳过文件”针对全新目标目录。网络接收量可能包含重传与边界辅助字节，不能直接等同于所选文件大小。

辅助清单损坏会报告错误并阻止静默恢复。请保留现场数据以便诊断，不要在运行中清理辅助目录。仅在确认可重新获取数据且程序已停止后备份、移走损坏的辅助目录，再执行校验/重试。
