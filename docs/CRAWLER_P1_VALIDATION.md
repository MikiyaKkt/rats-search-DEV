# 爬虫 P1 本地验证包

人工效果确认：**待用户验证**。

## 启动

解压 `RatsSearch-Windows-x64-crawler-p1.zip`，进入 `RatsSearch-Windows-x64` 文件夹。包内包含 Qt、MySQL 驱动、Manticore 和运行库，无需另行安装开发工具。

建议从该文件夹打开 PowerShell，使用独立数据目录启动：

```powershell
.\RatsSearch.exe --data-dir .\data-p1 --no-remember-data-dir
```

这会使用本次验证目录，并保留原有记忆的数据目录设置。首次启动完成协议确认，在设置中启用爬虫/索引功能。构建身份和可执行文件 SHA256 见包内 `build-info.json`。

也可双击包内 `Start-P1-validation.cmd`，它使用同样的独立数据目录参数。

## 本次变化

- 爬虫查重、分类、过滤、合并和逐条入库改由一个专用数据库线程执行。
- 索引、投票、文件详情、tracker、删除等写入通过同一个写协调器保持一致。
- 公告、候选和数据库任务有容量限制；停止时取消未开始任务，等待正在执行的数据库操作结束，再关闭该线程的连接。
- 元数据并发上限保持为 10；旧运行的回调不会把结果写入新一轮任务。

## 人工确认清单

1. 正常启动、启用爬虫，建议预热 5 分钟后观察约 15 分钟，记录新增种子数及大致 CPU、内存占用。
2. 爬取过程中搜索、切换页面、选择种子，观察界面响应是否改善，文件列表是否正常显示。
3. 连续关闭、重新开启爬虫约 5 次，观察是否恢复工作，有无卡死、崩溃或活动数异常。
4. 收录新种子后，观察活动列表、状态提示和 tracker 信息是否继续更新。
5. 正常退出并再次启动，检查数据库能否正常打开，搜索和详情是否正常。

网络没有公告、元数据超时或短时间没有新增，都不足以单独判定 P1 是否有效。本包尚未确认实际吞吐收益；若需要比较，请使用相同网络、设置和观察时长，并分别记录测试数据。

## 日志与反馈

按上述命令启动时，日志位于 `data-p1/rats-search.log`，可能还有轮转文件。默认每 5 秒输出一行 `[CrawlerMetrics]`，正常退出时输出最终快照。

反馈时建议附上：出现问题的时间、操作步骤、观察时长、新增数量，以及对应日志。可重点查看 `crawler.db_pending`、`crawler.db_pending_bytes`、队列拒绝/取消计数和 `crawler.index_inserted`。`db.main_query_calls` 包含 UI、P2P 等全部主线程查询，不能直接当成爬虫查询计数。

队列未持久化，队满时可能拒绝任务，停机时可能取消待执行任务；这些情况有相应计数，后续发现依赖新的网络公告。批量写入、可靠重试和并发调优属于后续阶段。
